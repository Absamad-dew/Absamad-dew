## Основные работы

- **[ChronoField](https://github.com/Absamad-dew/engineering-portfolio/tree/main/research)** — Нативное сжатие видео без потерь и хранение связанных вариантов. В опубликованном сравнении на трёх 1080p-источниках: **на 41,37% меньше байт, кодирование в 8,42 раза и декодирование в 4,98 раза быстрее** измеренного lossless AV1. [Условия сравнения](https://github.com/Absamad-dew/engineering-portfolio/blob/main/research/chronofield.ru.md).
- **[Aster](https://github.com/Absamad-dew/engineering-portfolio/blob/main/projects/aster.md)** — Автономные продажи и операционная работа с полноценной CRM: общение с клиентами, заказы, счета, записи, склад и задачи команды. Первый рабочий прототип сделал за два дня, затем продолжил интеграцию и работу над надёжностью.
- **[Video Studio](https://github.com/Absamad-dew/dlss5-video-studio)** — Приложение на C++20 / D3D12 / NVENC для воспроизведения, записи и стерео/VR. Открытая реализация и инженерные разборы со ссылками на код. В сопоставимом A/B нативный этап ускорен на **22,9%**.
- **[CoreBroker](https://github.com/Absamad-dew/engineering-portfolio/blob/main/projects/corebroker.md)** — Координатор вычислительных задач на Windows: физические ядра, блокировки общих ресурсов, управление процессами и измерения для параллельных сборок, тестов и работы агентов.
- **[Tervallis](https://github.com/Absamad-dew/engineering-portfolio/blob/main/projects/tervallis.md)** — Постоянная рабочая среда для проектов, экспериментов и агентских задач, с версиями операций и MCP-передачей поручений. Организовал с её помощью работу 20 агентов.
