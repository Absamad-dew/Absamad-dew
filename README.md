Published three-source 1080p results: **41.37% fewer bytes, 8.42× encode speed and 4.98× decode speed** against the measured lossless AV1 baseline. [Comparison conditions](https://github.com/Absamad-dew/engineering-portfolio/blob/main/research/README.md).
- **[Aster](https://github.com/Absamad-dew/engineering-portfolio/blob/main/projects/aster.md)** — Autonomous sales and operations with a full CRM: customer conversations, orders, invoices, bookings, stock and team workflows. First working prototype built in two days, followed by integration and reliability work.
- **[Video Studio](https://github.com/Absamad-dew/dlss5-video-studio)** — C++20 / D3D12 / NVENC application for playback, recording and stereo/VR. Public implementation and source-linked engineering notes; a matched A/B records **+22.9% native-stage throughput**.
- **[CoreBroker](https://github.com/Absamad-dew/engineering-portfolio/blob/main/projects/corebroker.md)** — Windows workload coordinator: physical-core allocation, shared-resource locks, process lifecycle and telemetry for concurrent builds, tests and agent jobs.
- **[Tervallis](https://github.com/Absamad-dew/engineering-portfolio/blob/main/projects/tervallis.md)** — Persistent workspace for projects, experiments and agent tasks, with versioned operations and MCP handoffs. Used to organize work across 20 agents.
